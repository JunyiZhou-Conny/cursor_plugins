# 分阶段 Prompt 模板

以下方括号由本次 brief 填写。它们是自然语言设计指令，不是任何工具的固定 JSON schema。
真实工具 payload 按宿主接口构造；某字段不接受指令就不能硬塞。

## A · 保留身份/设计的风格探索

> 使用〔主体照片/概念图〕作为〔身份/结构〕参考，以〔风格参考〕作为视觉方向。
> 必须保留〔3–5 个具体特征〕。把它转成〔风格〕，重点体现〔比例、线条、发束/结构、表面材质、配色〕。
> 表情/姿势为〔明确选择〕。不改变〔不可变项〕，不添加〔不需要的装饰〕。
> 输出单一清楚主体；这一步用于选定形象，不声称已经是三维模型。

## B · 建模参考整理

> 在不改变已确认角色/物件设计的前提下，把这张图整理成图转三维参考。
> 背景〔纯白/透明〕，保持主体关键外轮廓完整；构图为〔头像/半身/全身/物件〕。
> 调整〔具体遮挡/裁切/透视问题〕，保留〔用户希望保留的姿势与表情〕。
> 使用均匀柔和光线，保持鼻颊/曲面/凹凸的体积可读，避免把强阴影当永久颜色。
> 小细节按〔发束/厚实附件/合理连接〕表达，不加文字、水印、环境或新配饰。
> 静态展示不改成 T-pose；只有〔动画需求〕才采用〔A/T 姿〕。

## C · 一张补充视图（仅多视图已选择）

> 这是同一个已锁定的设计。请只输出〔真正侧面/背面〕，不输出拼图。
> 保持服装、材质、左右手、姿势、比例、配色和照明一致，只改变观察角度。
> 未知背面按〔已确认设计约束〕补全；不要新增图案或改变部件。
> 该图是设计补全，不是原照片隐藏信息的真实恢复。

## D · 贴图描述（仅有意改表面）

> 〔颜色〕的〔部位〕，〔哑光/金属/织物等〕外观，保持〔配色边界〕；避免新增文字与图案。

仅在当前 API 确实支持时作为 texture_prompt；不要求它创建独立眼球、修指骨或生成 CameraAction。
已有图的配色满意时可以省略这段，不与互斥贴图参考叠加。

## E · 单轮诊断

> 当前问题是〔截图/结构证据〕。我的假设是〔原因〕。
> 本轮仅主要改变〔输入/参数/贴图中的一项〕；保留〔其余固定项〕。
> 成本〔核价〕，权限〔授权证据〕，比较〔相同镜头/照明/检查项〕。
> 结果〔实测〕；结论〔改善/退步/无法归因〕；下一步〔保留/局部修/停止〕。

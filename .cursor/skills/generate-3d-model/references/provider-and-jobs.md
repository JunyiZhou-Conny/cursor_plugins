# 提供商、费用、断点与幂等

## 工具映射是运行时任务

需要的能力：查模型/文档 → 读 schema/价格 → 上传 → submit → status → result → 下载 → 验收。
fal 连接器可能使用 `get_model_schema / get_pricing / upload_file / submit_job / check_job / get_job_result` 等名称；这只是已见过的名称，不能据此调用未暴露工具。
已装连接器优先；通过工具发现机制读取真实签名，只发现一次后复用。发现动作不等于完成动作。
如果只暴露只读工具，不得假装 submit 已存在；检查可用 SDK/凭据，或交付明确的阻塞说明。
不要索要用户把 secret 发到普通聊天。SDK 使用环境变量或宿主凭据；不能写入前端、日志与 ZIP。

公开文档只验证产品能力，不验证用户账号是否付费、是否连对、是否有余额。
原生 Meshy 与 fal 是不同调用面；原生字段 `ai_model` 等不自动属于 fal 输入。
上传函数接 file path 的，传实际已存在的路径；接 URL 的，传真实可访问 URL；不要混用。
如 schema 支持 base64，只在工具调用内部程序化处理，小心负载限制；不在说明文字中输出原始数据。

## 静态人物的参考起点，不是默认执行配置

在重新核对后，可把 `meshy/v7/image-to-3d` 作为 Meshy 路线的候选；不把 v7 永久写成最新最佳。
最初成功案例执行了 standard + texture，remesh/PBR/rigging/animation/Ultra 关闭。
这条路线保留了一个大原稿，并没有自动得到网页资产；未来对低预算网页任务可选择不同取舍。
Ultra 不是修脸开关，贴图不是修几何开关，smart topology 不是独立眼球的保证。
模型是否可复现要看输入 seed 的实际支持，而不只看结果是否返回 seed。[S5/S7]

## 计费账本

至少记录：用户授权引文/时间、预算币种、总上限、每步估算、最大提交次数、是否允许自动迭代、保留预算。
分别累计 confirmed_actual、estimated_completed、reserved_inflight；**同一笔不重复计入**。
可用额度规划可用这些分类的保守总和，但必须标“规划值”，不是账户真实剩余额。
如果账单延迟，已完成的任务估算暂留占用；在得到实际值后替换，不把两者相加。
制图、多视图、再贴图与绑定都是独立的可能计费步骤；所谓每个模型价格未必涵盖它们。
按端点完整配置报价；2026-09-17 的历史 $1.20 仅作解释，下一次重新核价。[S8]

## 请求状态

建议状态（不是在冒充服务自身状态）：

```text
DRAFT → REFERENCE_READY → AWAITING_APPROVAL → READY_TO_SUBMIT
→ SUBMITTING → WAITING_PROVIDER → RESULT_AVAILABLE → QA → HANDOFF
                  ↘ SUBMISSION_UNKNOWN
                  ↘ BLOCKED
```

`RUN_STATE.json` 保存 active_job、request ID、真实查询 URL 和下一步，不用“记在聊天里”代替落盘。
提交前锁定单一执行者/创建提交标记；指纹帮助本地去重，但不是服务端幂等保证。
有 request ID 先查；没有 ID 且已发 POST、结果未知时，先查账户任务记录或请求人工确认，不能直接重发。
工具可读状态与 SDK 可读状态不统一时，记录原始返回和归一状态，不丢失 error。

服务 `COMPLETED` 可能携带失败信息；需要读取结果并核对实际资产。[S9]
轮询用服务间隔或退避到如 30–60 秒；具体数值是本 skill 的限流建议，非模型 ETA。
会话不够长则保存断点；只保留现有任务，绝不为“检查进度”再提交。
下载 403 与提交余额错误不能互相推定；鉴权、计费、schema、下载分别排查。
失败/超时/取消的退款不保证。不要把网页端 free retry 权益套进 fal。

## 资产与隐私

媒体 URL 可能公开可访问且受保留策略影响，因此及时归档；不能承诺永久有效。[S9]
任务 URL、CDN URL 不是账户凭据，但可能暴露个人资产，不把它们塞进可分享的通用 skill。
若用户要求私密托管，先确认提供商是否满足；不能看到“Private”界面文字就认为 CDN 链接有鉴权。
网络 GET 重试不会创建三维任务，但仍需受网络/服务政策限制，不循环请求。
结果地址失效优先取同一任务结果；还不可恢复时报告缺口，不自动买新任务。

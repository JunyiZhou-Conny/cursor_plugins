# 验证与行为评测

## 已执行的辅助工具测试

运行 `python3 -m unittest discover -s evals -p 'test_*.py' -v`。
使用合成 GLB 与 mock HTTP，不调用 fal、不生成真实人物、不消耗用户余额。
检查初始化、下载原子写入、错误页面、hash/大小、host/redirect、路径越界、私有素材排除、ZIP真实性等。
合成 GLB 只用于元数据清点测试，不宣称是完整符合 glTF 的生产资产。

## 待执行的 Agent 行为评测

`scenarios.json` 有独立 fixture 和必须/禁止行为。把 SKILL.md 加载给被评测 agent，逐个注入对应素材和工具返回。
记录实际工具调用、用户交互、生成授权、结果文件，再按条目评估。
不要为了测试关键安全场景真正收费；用模拟提供商，真实端到端测试另行获得预算。
14 个场景包含：模糊风格、缺照片、预算、已有任务、受理未知、COMPLETED错误、参数冲突、不一致多图、下载受限、网站与隐私。

辅助脚本通过，不等于 agent 行为评测通过，更不等于每个艺术风格都已经完成端到端验证。

# Identity versus sticker

You own whether the page is a character with stamps, or stamps with no character.

## Load

1. Product `taste-<site>` identity, sticker, and anti-pattern files if present.
2. Shared rubric tests 7, 13, 14, 15 in [`../critique-look/references/rubric.md`](../critique-look/references/rubric.md).
3. [`references/sticker-reduction.md`](references/sticker-reduction.md).
4. A still of the hero and of one stamp at chat size.

## Procedure

1. **Name the body.** What shape is Conny (or this site’s figure) without icons? If the answer is “Outfit type plus a CZ particle,” identity is type, not character.
2. **Audit each stamp.** One idea per stamp. Does it survive rotation, downscale, and a busy ground? Pale low-contrast marks fail. Ridiculously tall full-body stamps fail.
3. **Proximity.** Which stamps belong to the body, and which float in the void? Common region = a thought, not debris.
4. **Von Restorff.** The face (or the one signature) must isolate. If orbiting tool icons win, they are doing identity work they did not earn.
5. **Chanel cut.** Remove one sticker, one glow, or one orbit. If nothing is lost, it was wallpaper.
6. **Borrowed chrome.** A cloned developer kit with new nouns is a sticker laid on someone else’s body. Say that. Do not “polish” the clone.

## Output

Banned-decal list for this pass. Keep / cut / bind-to-body for each stamp. Symptom / cause / intervention / expected effect. One change. What not to change (do not delete the three featured systems to make room for more icons).

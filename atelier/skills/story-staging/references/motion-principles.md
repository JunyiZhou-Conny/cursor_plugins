# Motion principles

Public animation tests with numbers useful on a cartoony web character. Cite *The Illusion of Life* (Thomas and Johnston, 1981) as the book. Do not paste book prose. Numbered playful ranges follow the MIT [LottieFiles motion-design](https://github.com/LottieFiles/motion-design-skill) adaptation. Written there for UI cards. Use them on a figure, not as toast recipes.

| Test | What to look for |
| --- | --- |
| Squash and stretch | Soft body. Volume conserved. More squash reads as a softer toy. |
| Anticipation | Idle, hover, or click wind-up before the action. |
| Staging | One idea. Dim non-hero motion to about 40–60 percent. |
| Held poses | Hero loops need holds, not mushy interpolation. |
| Follow-through | Hair, ears, cloth, or stickers continue 50–150 ms after the body. |
| Slow-in / slow-out | Springs. Linear spatial motion feels cheap. |
| Arcs | Head turns, blinks, pointer paths. About 10–20 px of arc on UI-scale motion. |
| Secondary action | Blink or breathe. Never steal the main beat. |
| Timing | Weight. Heavy starts slower. |
| Exaggeration | Playful 15–25 percent on a cartoony brief. One hierarchy. |
| Solid volume | No twins. No collapsing mesh. |
| Appeal | Interesting to watch. Jerk, uniform timing, and abrupt stops kill it. |

Invert “skip squash for premium brands.” This brief is not a premium SaaS card.

Guilty Gear’s public note is niche: full interpolation can look “more 3D” and break a drawn style. Use it only when deciding stepped versus silky idle. Do not copy that cast.

# Materials and lighting

Target rig for a Conny-owned figure. The live page has no figure. Score live lighting as page chrome until one exists.

## Material

- Legal: clay, vinyl, plush, enamel.
- Illegal: 8K skin, wet eye, filmed hair, default MeshStandard greasy spec.
- Hair: mass, one break, one highlight.
- Stickers: enamel or print that matches the toy, not a second PBR object.

## Light

- Key direction first, from above.
- Fill keeps the dark side readable (Half-Lambert or a short ramp).
- Rim lifts the character off `#0b0b11` if the page stays dark.
- Shadows cool and simple. Only big casters.
- Squint. One value peak on the face.

## Rejected passes

- Studio HDRI “to look expensive.”
- Flat cream type on crushed black as a substitute for volume.
- Token-monitor widget materials (dark glass cards) used as the character.

# Taste loader (MeConny)

Copy this folder to the *product* repo as `.cursor/skills/taste-meconny/`. Do not keep a second copy of atelier procedures here.

This marketplace checkout is [cursor_plugins](https://github.com/JunyiZhou-Conny/cursor_plugins). The site is [MeConny](https://github.com/JunyiZhou-Conny/MeConny). If you are not in the site repo, say so and keep working from this seeded template.

## Open in this order

| Request | Files |
| --- | --- |
| Any look change | `DESIGN.md`, then `vocabulary.md` |
| Who is this | `identity.md`, `accepted-refs.md` |
| Weak outline | `identity.md` (anchors), `anti-patterns.md` |
| Stickers / icons / charm | `sticker-rules.md`, `rejected-refs.md` |
| Plastic / flat / photographic | `materials-lighting.md` |
| Arrival / idle / same fade | `motion.md` |
| After a verdict | `before-after.md`, `iteration-log.md`, `decisions.md` |

Then run atelier `critique-look` on a still of https://me-conny.vercel.app (or local `npm run dev`).

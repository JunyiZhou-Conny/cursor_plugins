# Sticker rules

## Bind to the body

A stamp is legal when it is a pose or a prop of the character (a lab coat clip, a small 周, a toy pipette). It must survive transparent PNG, rotation, and 64px.

## Do not treat as stickers

- Devicon / Simple Icons in a marquee.
- Skill-universe planets around `CONNY SKILL`.
- GitHub / OpenAI / AWS marks as personality.
- The leftover Token Monitor widget chrome on Pediatric Savior.

## Caps

One hero stamp in the first viewport. Supporting stamps stay in common region with the body. Alt text on every stamp.

# Atelier

Visual identity specialists for a character-led site. Critique the look before suggesting a change. One concern per skill.

This pack is not a second pstack. Type `/poteto-mode`. The Look playbook names these skills. Specialists stay hidden (`disable-model-invocation: true`).

## Install

```text
/add-plugin atelier
```

Pair with `/add-plugin pstack` (router) and `/add-plugin cursor-team-kit` (camera). Identity memory lives in the *product* repo as `.cursor/skills/taste-<site>/`, not here.

## Skills

| Skill | Job |
| --- | --- |
| `critique-look` | Entry. Score the shared 17-test rubric. Name the three biggest problems, one highest-leverage change, and what not to change. |
| `strengthen-silhouette` | Readable mass, pose, and contrast against ground. |
| `identity-vs-sticker` | Charm that belongs to the body versus glued-on decals. |
| `materials-and-light` | Surface honesty and light that sells volume. |
| `story-staging` | One beat (welcome, wander, gift) plus motion principles. |

## Product memory

Copy [`skills/critique-look/references/taste-product-template/`](skills/critique-look/references/taste-product-template/) into the site repo as `.cursor/skills/taste-<site>/`. The template is not a sixth slash skill. The MeConny seed is already in that folder. Paste it into [JunyiZhou-Conny/MeConny](https://github.com/JunyiZhou-Conny/MeConny) when you want project-local taste.
